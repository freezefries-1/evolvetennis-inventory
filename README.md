# evolvetennis-inventory

Evolve Tennis System: stock, purchasing, sales, reporting and financials for Evolve Tennis, distributor of MSV tennis strings and accessories.

- `index.html` — the website home page. Built from `design/msv-inventory.html`; after changing that file, run `./scripts/build-site.sh` to update it.
- `design/msv-inventory.html` — the app (single self-contained file)
  - **Phase 2 (live):** products, variants and SKUs, stock levels, inventory value, reorder levels, manual stock adjustments, stock movement history, product categories
  - **Phase 3 (live):** suppliers, purchases with multiple items and additional costs, Draft → Ordered → Received statuses, automatic stock-in on receipt (once only), purchase reversal, purchase history on supplier and variant pages
  - **Phase 4 (live):** customers, sales with multiple items, line and order discounts, shipping/other charges, Draft → Confirmed → Completed statuses, payment status, automatic stock-out on completion (once only), cost snapshots and gross profit, sale reversal, customer and SKU sales history, live dashboard and reports
  - **Phase 5 (live):** unified stock movement ledger with permanent movement IDs, movement detail pages, read-only history (corrections are new movements), customer returns (partial, condition-based restocking, reversal), supplier returns, improved stock adjustments (increase / decrease / set exact with required reason and notes), stock count reconciliation, audit trail, ledger integrity check, CSV export, inventory movements report and net sales after returns
  - **Phase 6 (live):** dashboard and reports driven by real data, with a shared reporting period (today to last year, or a custom range) remembered for the session and comparisons with the previous equivalent period. Reports cover overview and business snapshot, sales (gross, returns, net), gross profit and margin, product performance and best sellers, inventory value, low stock, slow-moving and never-sold stock, customers, markets (countries) with drill-down, purchases and suppliers, returns, and an opening-to-closing stock movement report. Every report table sorts and exports to CSV with the current filters
  - Report rules: completed sales and completed returns only, received purchases only (at the exchange rate stored when received), cost of goods from each sale's stored cost snapshot, inventory at current stock × current cost price. Gross profit is net sales minus cost of goods sold (from Phase 7; product-level figures exclude order shipping and other charges)
  - **Phase 7 (live):** app renamed to Evolve Tennis System; Financials section with operating expenses, capital equipment and other income (EXP- / INC- references, custom categories, payment methods, statuses, attachment link field, detail pages with audit history), Net Operating Profit (gross profit − operating expenses + other income) and Net Cash Result (− capital equipment), profit trend and breakdown, expense breakdown and trend, landed cost allocation by quantity or value with preview, product / customer / country profitability, financial reports and CSV exports. Inventory purchases are never counted as expenses, expenses never change stock, and completed sales keep their stored cost
  - **Phase 8 (live):** sign-in with a first-run admin setup and a one-time recovery code, hashed passwords, idle timeout that locks the screen without losing an open form, Admin and Staff roles plus custom roles with a permission matrix (checked on every page, action and typed address; staff don't see profit, margins or expenses unless allowed), user management with temporary passwords, created by / updated by on records, expanded Settings (business, inventory, sales and purchases defaults, numbering prefixes, financial, date and currency formats, rows per page), CSV import for products, customers and suppliers with validation, preview and duplicate handling, an Export Centre, full system data export and restore, notification centre, global search, quick actions (Ctrl+K), System Health, Activity Log with filters, pagination, unsaved-changes protection, double-click and duplicate-post protection, a large-adjustment warning, protection against another tab overwriting newer data, and a phone layout with quick tasks
  - **Phone layout:** on screens up to 640px wide, tables show as labelled cards, long filter lists fold behind a Filters button, forms open as full-height sheets with the save bar always in view, text fields use 16px text so iPhones don't zoom in, and a bottom tab bar covers Home, Stock, Sales and Purchases plus the full menu. The site can be added to the home screen with its own name and icon (`apple-touch-icon.png`)
  - Phase 8 limits: everything is still stored in this browser only, so sign-in and permissions protect the screens but not the stored data from someone with developer tools on the device. See `docs/BACKUP.md`
  - Money in other currencies is converted to SGD with exchange rates you enter in Settings (not live rates); each completed sale keeps its own rate
- `tests/phase2.spec.js` to `tests/phase8.spec.js` — browser tests for each phase's checklist (`node tests/phase8.spec.js`, needs Playwright). `tests/phone.spec.js` checks the phone layout. `tests/auth.js` signs the tests in
- `docs/BACKUP.md` — where the data is stored, how to back it up and restore it, the limits of browser-only storage, and the plan for moving to a hosted database (Supabase)
- `design/DESIGN_GUIDE.md` — rules for every HTML design in this project
- `design/reference/` — the approved reference prototype and the design system it uses
