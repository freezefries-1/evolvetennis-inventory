# evolvetennis-inventory

Inventory, purchasing and sales tool for Evolve Tennis.

- `index.html` — the website home page (Phase 1 prototype). Built from `design/msv-inventory-phase1.html`; after changing that file, run `./scripts/build-site.sh` to update it.
- `design/msv-inventory-phase1.html` — Phase 1 clickable prototype, sample data only
- `design/DESIGN_GUIDE.md` — rules for every HTML design in this project
- `design/reference/` — the approved reference prototype (`Evolve Inventory.dc.html`) and the design system it uses
