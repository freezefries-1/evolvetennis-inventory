# Evolve Tennis Inventory

Internal stock, purchasing and sales tool for Evolve Tennis, a Singapore distributor of
MSV tennis strings, grips and accessories.

## HTML designs

Whenever you are asked to create or change an HTML design, page, screen, mock-up or
prototype for this project:

1. Read `design/DESIGN_GUIDE.md` first and follow it.
2. Use `design/reference/Evolve Inventory.dc.html` (the approved prototype) as the source
   of truth for layout, markup patterns, copy and sample data. It is built on the
   SportCraft design system in `design/reference/_ds/` — see its `readme.md` for the
   full brand rules.
3. Key rules in brief: Manrope for all text with tabular numbers; deep court-green
   sidebar (`#0B3227`) and primary actions; warm off-white page (`#FAF9F6`) with white
   8px-radius cards and `#E3E7E9` hairlines; optic yellow-green (`#D6F25B`) as a rare
   accent only; uppercase 10.5–11.5px micro-labels; prices in `S$` (SGD); Lucide icons;
   sentence case, no emoji, no exclamation marks, verb + object buttons.
4. Save new designs in `design/` as self-contained `.html` files.

Don't edit anything in `design/reference/` unless asked — it is the imported reference.
